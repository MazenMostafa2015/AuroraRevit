The proxy is operable, observable, and resilient

Default runtime state
RUNNING
http://localhost:5000
If port 5000 is occupied, the resolver and GUI move to port 5001 and report the active endpoint.
WPF GUI host
Start/stop controls, Running/Starting/Stopped/Unhealthy states, endpoint display, and clean shutdown.
AiProxy.Desktop
Observability
Health polling against /health, process output capture, live log view, and active endpoint probing.
Release shape
Self-contained win-x64 publishing for both the headless proxy and the GUI, with GitHub artifact upload.

04 / security & reliability

Invalid inputs and provider failures become controlled states

Ring 01
Prompt Sanitization
Length Constraints
Hard enforcement of a 12,000-character payload boundary to prevent runaway buffer spikes.
Character Filtering
Strips hazardous ASCII control codes while preserving necessary formatting whitespace.
Empty Guard
Rejects whitespace-only queries prior to invoking downstream LLM pipelines.
Ring 02
Credential Isolation
IOptions DI Binding
ASP.NET Core options pattern strictly separates runtime settings from secrets storage.
Format Verification
Enforces prefix and length structural rules before initializing client SDK instances.
Zero Secret Leakage
API keys are completely excluded from logs, error traces, and client responses.
Ring 03
Error Normalization
Deterministic 400s
Malformed inputs immediately return structured validation error envelopes.
Controlled 503s
Unconfigured state provides clear setup guidance rather than crashing the pipeline.
Sanitized 502s
Upstream provider exceptions are scrubbed into clear, actionable UI notices.

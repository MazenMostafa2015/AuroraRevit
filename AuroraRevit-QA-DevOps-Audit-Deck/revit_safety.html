Faster Review Without Unsafe Automation

Accelerate developer workflows while maintaining strict execution safeguards in Revit.
Review & Transfer Flow
In-Chat Execution Copying
New Copy this Execution button added directly into assistant chat bubbles for single-click clipboard transfer.
Dedicated WPF Code Viewer
Opens generated C# snippets in a syntax-highlighted review window with copy and RevitPythonShell transfer options.
Strict User Approval Boundary
AI-generated code is never auto-executed against the Revit document without explicit human inspection and action.
Revit Guardrails
ExternalEvent Modeless Dispatch
All async proxy events marshal safely into Revit's main UI thread through dedicated IExternalEventHandler implementations.
Transaction Isolation
Mutations are wrapped in using (Transaction tx = new Transaction(doc, "AI Action")) to ensure atomic rollback and crash prevention.
Safe Selection Execution
Element selection queries execute via FilteredElementCollector with validated document scopes.

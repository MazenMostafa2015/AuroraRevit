# AuroraRevit v2.1.1 — Hybrid Fallback and Proxy Startup Fix

AuroraRevit v2.1.1 is a hotfix release focused on the workstation failures reported during Revit testing.

## Provider and model configuration

- Added `AURORA_OLLAMA_MODEL` support to the C# hybrid client and the IronPython pyRevit router.
- Custom Ollama model names such as `deepseek-coder:latest`, `codellama:latest`, `qwen2.5-coder:7b`, and `mzeada/RevitCoder:latest` can be selected through Quick Settings or the environment variable.
- Preserved endpoint normalization so users enter `http://localhost:11434` without appending `/api`.
- Kept the direct Ollama HTTP path compatible with IronPython 2.7; the modern `ollama-python` package remains optional for workstation diagnostics only.

## Hybrid fallback

- Added true C# Smart Fallback between OpenAI Cloud and Ollama Local.
- If the selected provider fails and the alternate provider succeeds, the request reports that fallback was used without changing the saved provider preference.
- If both providers fail, the error includes primary and alternate provider context.

## Proxy startup

- Added a per-user Windows Startup shortcut named `AuroraRevit Proxy (automatic)`.
- The shortcut starts the proxy GUI when Windows starts, allowing Cloud mode to be available before Revit launches.
- Existing port resolution remains: the proxy uses port 5000 when available and falls back to port 5001.

## Validation

The release passed the pyRevit compatibility simulation, hybrid-router simulation, 14-button release contract, Python compilation, installer contract checks, workflow metadata checks, and whitespace validation. Windows CI is the authoritative check for Revit compilation, self-contained .NET publishing, Inno Setup compilation, and installer publication.

## Workstation action

After installing v2.1.1, restart Windows or launch `AuroraRevit.ProxyGui.exe` once. Verify `http://localhost:5000/health` or `http://localhost:5001/health`, then test OpenAI Cloud and Ollama Local independently. Ollama Local can continue operating offline without the Aurora proxy when selected explicitly.

The installer does not store OpenAI credentials. Configure the proxy through user-secrets or the `OpenAI__ApiKey` environment variable.
